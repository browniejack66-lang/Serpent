# 文件夹隐私锁

给文件夹加一把密码锁：锁定后，这个文件夹及其所有子目录里的内容不会在 Serpent 中显示，浏览器扩展也不会向你展示或允许保存到这些目录。

> 说明：这是应用内的隐私保护，**不是加密**。文件仍以原样保存在磁盘上，其他程序、系统文件浏览器或系统备份仍可能读到原始文件。隐私锁用于避免在 Serpent 内（以及扩展保存菜单里）误看到这些内容。

## 设置保护

1. 在左侧目录中右键目标文件夹，选择「隐私锁…」。
2. 在对话框中选择「设置保护」，输入密码并确认。
3. 设置完成后，该文件夹立即进入**锁定**状态。

锁作用于整个目录树：受保护文件夹下的所有子目录一并生效，无需逐个设置。

## 解锁与再次锁定

- 解锁：右键受保护文件夹 →「隐私锁…」→ 选择「解锁」→ 输入密码。解锁只对当前这次打开的资源库有效。
- 立即锁定：在同一个对话框中选择「立即锁定」，即可马上隐藏内容。
- 关闭资源库或重启 Serpent 后，所有受保护文件夹会自动回到**锁定**状态。
- 密码错误或取消操作时，文件夹保持锁定，不显示任何内容。

## 修改密码与取消保护

- 修改密码、取消保护都需要先输入当前密码。
- 取消保护后，该文件夹恢复正常显示。

## 锁定后的效果

- 侧栏中受保护的根文件夹仍会显示名称和锁图标，但其中的子文件夹、素材数量、封面都会被隐藏。
- 搜索、全部素材、合集、最近浏览、标签结果、缩略图、大图和预览都不会显示锁定范围内的内容。全局标签名称仍保留，但计数不包含锁定素材。
- 浏览器扩展：锁定的文件夹及其子目录在右键保存菜单、拖拽保存目录树、目录选择器中都不再出现；即使桌面端已经解锁，也不会向扩展开放这些目录。桌面端锁定/解锁后，已打开的扩展菜单也会及时刷新（连接正常时无需等待定时检查）。
- 如果保存目标在上传前变为锁定，扩展会提示你重新选择目录，不会悄悄改存到别的地方。

## 忘记密码怎么办

应用不提供密码找回或免密码取消保护功能。忘记密码后，仍可通过系统文件浏览器访问磁盘上的原始文件。请妥善保管密码。

## 注意事项

- 解锁只在桌面端进行，浏览器扩展不会接收或保存你的密码。
- 旧版客户端和旧版浏览器扩展可能不认识隐私锁状态，建议更新到支持该功能的版本。
- Serpent 的整库导出会在存在锁定目录时拒绝开始；请先解锁所有受保护范围。解锁后的导出以及系统层面的文件复制或备份仍包含原始文件，隐私锁不会加密这些副本。
