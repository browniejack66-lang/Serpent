# 文件夹隐私锁

状态：已实现（src/worker/folder-privacy.ts、src/worker/library-service.ts、src/main/extension-folder-privacy.ts、src/main/folder-privacy-transition.ts 及扩展客户端相关代码）。本文档描述当前的实际实现，以及刻意保留的边界。

## 目标与范围

为指定文件夹及其全部子目录提供密码解锁机制，未解锁时在 Serpent 内不展示其中的素材。浏览器扩展遵循同一锁定状态，始终隐藏受保护目录及其后代。

这是**应用内隐私保护**，不是加密。受保护文件夹中的原文件仍以原有方式存放在磁盘上，隐私锁不会改变文件本身。因此：

- 磁盘上的文件、其他程序、备份/导出内容以及拥有直接文件访问能力的工具仍可读取这些原文件。
- 旧版客户端、旧版扩展不理解此状态，可能仍能看到相关内容。
- 忘记密码后没有后门恢复手段，只能通过移除保护（需要原密码）或在文件系统层面处理。

## 数据模型与作用域

- 每个受保护的**根目录**对应 folder_privacy 表中的一行，主键为 (library_id, scope_kind, scope_id)，其中 scope_kind 为 managed（普通目录）或 linked（链接目录根）。子目录不单独存储，读取时按祖先路径包含关系（祖先相对路径是后代的前缀）推导锁定范围。
- 普通目录记录其相对路径；目录被重命名或移动时，读取锁状态会使用其**当前**相对路径，无需修改记录。链接目录根锚定在链接的 folder_id 上；链接子目录使用包含链接根与相对路径的独立编码 ID；重命名时在同一事务内更新保护记录并重新锁定，相邻子目录可使用不同密码。
- 密码使用带随机盐的 scrypt-v1 校验值（16 字节盐、64 字节派生密钥）存储，验证时使用常量时间比较。**密码本身不明文持久化。**

## 解锁状态（内存、按资源库）

- 解锁状态保存在内存中，按打开的资源库维护，**不落盘**。
- 关闭资源库或重启应用后，所有受保护目录恢复为**锁定**。
- 刚设置保护的目录默认处于锁定状态；修改密码后重新锁定，移除保护后恢复正常访问。

## 桌面端交互

- 文件夹右键菜单提供「隐私锁…」入口，通过对话框完成设置保护、解锁、立即锁定、修改密码和取消保护。这是**对话框操作**，不是点击目录即自动解锁。
- 解锁时在对话框中输入密码；错误或取消时保持锁定，不展示内容。取消保护和修改密码需要先验证密码。
- 锁定覆盖整个目录树：侧栏与文件区保留受保护根目录的名称与锁图标，但隐藏其所有后代目录、素材数量与封面。
- 搜索、全部素材、合集、最近浏览、标签结果、详情、缩略图、原图和预览遵循同一规则，无法从其他入口读取锁定内容。显示「已忽略」的素材也不会因此暴露锁定范围内的内容。
- 立即锁定时，主进程会先撤销正在进行的内容读取（包括已经发往 Worker 等待处理的请求），再改变访问状态，并清除缓存、使已打开的页面与预览重新加载。

## 浏览器扩展

- 锁定时，右键保存菜单、拖拽保存目录树、目录选择器和最近保存/浏览记录都**不显示**受保护根目录及其后代，也不返回其名称、路径、计数或封面。
- 由桌面端的本机接口统一过滤目录与内容并给出可见目录白名单；扩展界面隐藏不能替代接口校验。通过旧目录 ID 访问或保存到锁定位置会被拒绝。
- 受保护根目录及其后代**即使桌面端已经解锁也始终对扩展隐藏**。桌面端的解锁只影响桌面端自身的浏览，不向扩展放开受保护树。
- 扩展在每次保存前都会重新向桌面端获取最新目录状态再校验目标；无法确认状态时按失败处理（提示重新选择可用目录），不会继续使用缓存中的受保护目录。
- 桌面端重新锁定后，扩展会**立即**清除缓存与最近使用项，并关闭已经打开的保存菜单。
- 为了做到「立即」而非最多等待 30 秒的定时重连，扩展在连接后维护一个针对本机接口的长轮询（`GET /privacy-events?since=<版本号>`）：
  - 桌面端每次改变隐私状态（保护/解锁/锁定/移除/改密）都会推进一个**不透明、单调递增的版本号**（整数，不含任何目录或资源库 ID），并立刻唤醒所有挂起的轮询。
  - 轮询最长挂起约 20 秒（心跳上限），随后以当前版本号返回，避免无限连接；扩展据此立即清缓存并重建菜单。
  - 断线后按上限内的退避重连，避免空转；服务关闭或扩展断开时会清理挂起的轮询，不留悬挂连接。
- 已选择的保存目标在上传前变为受保护或锁定时，提示重新选择，**不会静默改存到其他位置**。
- 解锁只在桌面端完成，扩展**不接收也不保存密码**。

## 兼容与边界

- 接口会随目录列表返回一个不透明的隐私版本号（哈希，不含内部 ID）；长轮询接口另有一个不含任何内部 ID 的单调递增整数版本号。新版扩展据此判断状态是否变化；状态无法确认时新版扩展按失败处理。
- 旧版扩展不认识隐私状态，无法保证可靠隐藏，请更新到支持隐私锁的版本。
- 浏览器扩展属于独立仓库（Serpent-Extension），扩展侧隐藏属于纵深防御，权威过滤始终在桌面端本机接口。
- **整库导出要求全部解锁**：存在锁定范围时拒绝导出，开始复制前再次校验。解锁后的导出会包含原始文件；系统层面的备份与文件复制也不受应用隐私锁控制。

## 验收场景

以下为当前实现应满足的行为（对应已实现的单元/集成测试覆盖的主要路径）：

1. 普通目录、嵌套目录和链接目录均可设置保护；错误密码、取消解锁、重启及重新开库后不能查看内容。
2. 锁定素材无法经搜索、合集、最近浏览、封面、缩略图、原图、媒体链接及自动化入口绕过访问限制。
3. 扩展的右键菜单、拖拽菜单、最近使用项及接口响应均隐藏锁定目录和后代；受保护树即使桌面解锁也对扩展隐藏；旧 ID 与旧缓存不能继续用于读取或保存。
4. 在预览、上传或扩展菜单打开期间重新锁定，相关内容和缓存被撤销，保存请求不会静默落到其他目录。
5. 修改密码、移出保护范围、重命名和移动目录时，保护关系按预期维护；未保护目录继续正常使用。
6. 应用升级后配置仍在，默认锁定；旧库正常打开，迁移与资源库可用性检查通过。

## 已知限制

- 应用内保护，非加密：磁盘文件、备份/导出内容与其他程序仍可读取原文件。
- 应用不提供密码找回或免密码移除保护；忘记密码后仍可在文件系统层面访问原文件。
- 旧版客户端与旧版扩展可能不遵守锁定状态。
- 每个受保护根目录各自设置密码，不提供同一资源库的统一隐私密码，也不提供空闲超时或锁屏自动锁定。
